Flip

Draw frame by frame and play it back as an animation. Version 0.1.1.

Install

flatpak install --user https://kjlape.github.io/flip/io.github.kjlape.Flip.flatpakref

Then run it from your app launcher, or with flatpak run io.github.kjlape.Flip. Updates arrive with flatpak update.

The repository is signed with this key. Source and releases are on GitHub.
